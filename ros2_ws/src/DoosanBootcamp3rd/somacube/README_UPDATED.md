# 🤖🧠 AI 기반 소마큐브 조립 시스템

OpenAI GPT-4o를 활용한 지능형 소마큐브 해법 생성 및 로봇 그랩 최적화 시스템

## 🚀 핵심 기능

### 🧠 AI 기반 해법 생성
- **DQN 모델**: 기존 강화학습 기반 해법 생성
- **OpenAI API**: GPT-4o를 사용한 지능형 해법 생성  
- **하이브리드 시스템**: 두 방식을 선택적으로 사용 가능

### 🤖 AI 기반 그랩 최적화 (NEW!)
- **지능형 그리퍼 자세 최적화**: 물리적 제약조건을 고려한 최적 자세 선택
- **조인트별 특이점 회피**: AI 기반 로봇 특이점 감지 및 회피 전략
- **충돌 회피 추론**: 실시간 충돌 위험 분석 및 회피 방법 제안
- **적응형 학습**: 실행 결과를 바탕으로 한 실시간 성능 개선

### 🔄 실시간 학습 시스템 (NEW!)
- **피드백 기반 학습**: 성공/실패 사례를 통한 지속적 개선
- **패턴 인식**: 과거 경험을 바탕으로 한 전략 최적화
- **실패 분석**: AI 기반 실패 원인 분석 및 개선 방안 제시
- **성능 모니터링**: 실시간 성공률 추적 및 분석

### 🎯 통합 로봇 제어
- **실제 로봇 팔 제어**: Doosan 로봇과의 완전한 통합
- **물리적 조립 실행**: 정밀한 소마큐브 조립 수행

## 🔧 설정 및 실행

### 1. 환경 설정
```bash
# 필요한 패키지 설치
pip install -r requirements.txt

# .env 파일 생성
cp .env.example .env
```

### 2. .env 파일 편집
```env
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4o
OPENAI_MAX_RETRIES=3
```

### 3. 시스템 테스트
```bash
# 소마큐브 해법 생성 테스트
python test_openai_solver.py

# 그랩 최적화 시스템 테스트
python test_openai_grasp.py
```

### 4. 실제 로봇 실행
```bash
# ROS2 환경에서 실행
ros2 run somacube RL_with_robot2

# 실행 후 선택:
# 1 = DQN 모델 사용
# 2 = OpenAI API 사용 (권장)
```
